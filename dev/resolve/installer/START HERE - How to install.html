Install JMG Ultra Studio in DaVinci Resolve

Version __VERSION__ · about 2 minutes · needs DaVinci Resolve Studio 19.1 or later (the free DaVinci Resolve can't run plugins)

1. Install

  1. Quit DaVinci Resolve if it's open. Save your work first – Resolve only looks for plugins when it starts.
  2. In this folder, double-click Install on Mac.command.
    If the Mac says it “can't be opened” or “Apple could not verify…”, click Done (not Move to Bin). Then open System Settings › Privacy & Security, scroll down to “Install on Mac.command was blocked…” and click Open Anyway, type your Mac password, then Open Anyway again. This is how macOS Sequoia (15) and later work; on older macOS, right-click the file › Open › Open.
    Or, from Terminal: open Terminal (Applications › Utilities), type bash  (with a space after it), drag Install on Mac.command into the Terminal window and press Return.
  3. A Terminal window opens and shows each step with a ✓ as it's done.
    If it asks for your Mac password, type it and press Return – nothing shows while you type, that's normal. It's needed because Resolve's plugin folder is shared by everyone on the Mac.
  4. When you see ✓ Installed, press O to open DaVinci Resolve straight away, or any other key to close the window.
  1. Unzip the download first: right-click the zip › Extract All › Extract. Running the installer from inside the zip won't work.
  2. Quit DaVinci Resolve if it's open. Save your work first – Resolve only looks for plugins when it starts.
  3. In the unzipped folder, double-click Install on Windows.bat.
    If a blue “Windows protected your PC” box appears: click More info › Run anyway.
  4. A black window opens and shows each step as it's done. If Windows asks “Do you want to allow this app to make changes?”, click Yes – Resolve's plugin folder is shared by everyone on the PC. The installer carries on in a new window.
  5. When you see Installed, press O to open DaVinci Resolve straight away, or any other key to close the window.

2. Open it in Resolve

  1. Open DaVinci Resolve Studio and open a project (any project – or make a new one). The plugin menu only appears with a project open.
  2. In the menu bar at the top choose Workspace › Workflow Integrations › JMG Ultra Studio.
  3. JMG Ultra Studio opens in its own window. Drag it beside Resolve, or onto a second screen.
  4. On the Home tab press Check my setup. It checks Resolve Studio, the version and that every tool has what it needs, and says plainly how to fix anything that's missing.

3. Start using it

  1. Open a timeline in the Edit page (most tools work on the timeline that's open).
  2. Pick a tool from the rail on the left. Good first tries: Story (interviews → themes, soundbites and a first cut), Selects (finds the usable shots), Silence Cut.
  3. Most tools build a new timeline rather than changing the one you're cutting, so your edit stays as it was.
  4. The Guide (Home › Guide) explains every tool. In Resolve a sequence is a timeline and the Project panel is the Media Pool.

If something's not right

The Mac won't open the installer (“can't be opened”, “Apple could not verify…”)
Click Done, then System Settings › Privacy & Security › scroll down › Open Anyway next to “Install on Mac.command was blocked”. Or use the Terminal way in step 2 above – it always works.
“Workflow Integrations” isn't in the Workspace menu, or JMG Ultra Studio isn't listed
Open a project first. Quit Resolve completely and open it again (it reads plugins only when it starts). Check it's DaVinci Resolve Studio – in Resolve choose DaVinci Resolve › About DaVinci Resolve: it must say Studio, version 19.1 or later.
The installer says Resolve Studio's plugin support is missing
Install or update DaVinci Resolve Studio from blackmagicdesign.com (the free version doesn't include it), then run the installer again.
The installer waits for Resolve to quit
Save, then quit Resolve (DaVinci Resolve › Quit on a Mac, File › Quit on Windows). The installer carries on by itself.
The window is blank or says it can't connect
Close the JMG Ultra Studio window and open it again from the Workspace menu. If it's still blank, run the installer again.
Updating to a new version
Quit Resolve and run the new installer. Your settings and analysis results are kept.
Removing it
Quit Resolve and double-click Uninstall on Mac.command or Uninstall on Windows.bat.
